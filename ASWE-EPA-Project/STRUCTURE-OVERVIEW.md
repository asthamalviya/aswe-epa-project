## How to Add Screenshots

### For Each KSB Folder:
1. Extract screenshots from your PDF (e.g., using Preview on Mac)
2. Save as PNG: `governance-framework.png`, `business-alignment.png`, etc.
3. Place in the KSB folder
4. Reference in evidence-new.md: "See screenshot: governance-framework.png"

### Recommended Screenshots Per KSB:
- KSB-K7 (Governance): Framework diagram, organizational chart, governance model comparison
- KSB-S8 (Strategy): Strategy diagram, technology options comparison, alignment chart
- KSB-K9 (Leadership): Change management plan, stakeholder engagement timeline
- KSB-K10 (Business Value): ROI calculation, benefits tracking, before/after comparison
