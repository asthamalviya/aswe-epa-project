# Portfolio (AM2)

**What it is:** Assessment Method 2 of the End Point Assessment. Your seven module submissions form the portfolio; there is no word count. It underpins a 60-minute professional discussion against the 34 AM2 KSBs. You can refine the submissions until Gateway.
**Separate from:** the capstone (`../08_capstone-AM1/`) and the Module 7 brief work (`../07_module-7/`).

## Start here

| File | Use |
|---|---|
| `portfolio-index.md` | Each AM2 KSB mapped to the module evidence, backup and readiness |
| `discussion-question-bank.md` | Likely discussion questions with answer outlines; Distinction KSBs first |
| `evidence/corrections-pack.md` | Replacement text for every Must fix in the module submissions |
| `evidence/your-answers.md` | Questions only you can answer; they fill the gaps in every draft |

## Folders

| Folder | Contents |
|---|---|
| `module-assessments/` | Your seven submitted module PDFs |
| `evidence/` | Coverage tracker, fix list, corrections pack, evidence drafts by module and by KSB |
| `multiverse-pages/` | Multiverse Portfolio Readiness Tool pages saved per project |
| `ksb-reference/` | Multiverse pages per AM2 KSB (wording, criteria, sample questions) |
