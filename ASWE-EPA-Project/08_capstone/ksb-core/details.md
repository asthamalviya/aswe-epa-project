# Capstone Project - Core Evidence

## What the Capstone Is About

The Capstone Project is your opportunity to demonstrate integration across all KSBs learned in Modules 1-7. It should be a substantial, real-world project that showcases multiple competencies working together: technical delivery, leadership, governance, testing, and accountability.

## What Makes a Strong Capstone

**Scope:** A project significant enough to take 3-6 months and involve 8+ KSBs

**Example Projects:**
- Build and deploy a product (MVP → production with real users)
- Lead a team through a significant technical transformation
- Architect and implement a system handling scale/security/performance
- Migrate critical systems with zero downtime

**Not Suitable:**
- Single feature implementation (too small)
- Theoretical design (no real execution)
- Small script or tool (not substantial enough)

## How Capstone Evidence Works

**Structure:** One core folder (ksb-core) with three files:
1. `details.md` - What the capstone demonstrates
2. `evidence-submitted.md` - What you showed examiners initially
3. `evidence-new.md` - Additional evidence to strengthen capstone grade

**Key Difference from Modules 1-7:**
- Modules focus on individual KSBs
- Capstone focuses on integration (multiple KSBs in one project)
