# Module 6: Cloud Computing & Infrastructure

## Module Overview
Module 6 focuses on cloud architecture, networking, security requirements, response to change, and teamwork tools.

## KSBs to Evidence

### ksb-k16: Cloud Networking Concepts
- Explain networking in cloud architecture
- Discuss TCP/IP, DNS, TLS, API Gateways, load balancing
- Link networking choices to user experience and governance
- Provide evidence from deployed network (routing, latency testing)

### ksb-k24: Functional & Security Requirements
- Define functional, non-functional, and security requirements
- Design compliant solutions
- Compare alternatives (storage, compute, AI services)
- Provide testing evidence (latency, load, security)

### ksb-s20: Respond to Changing Priorities
- Show real development issues and how you adapted
- Compare options for solutions
- Explain chosen approach and team impact
- Link technical fixes to team outcomes

### ksb-k28: Teamwork Tools in Cloud Development
- Evaluate tools (Git, CI/CD, infrastructure-as-code, testing)
- Link tools to productivity and code quality
- Quantify tool effectiveness (defects caught, debugging time saved)
- Provide collaboration artefacts (PR comments, code review, issue board)

## Feedback Summary
**Overall Grade:** A
**Key Gaps for A+:** More deployed failure testing evidence, visible collaboration artefacts (PR comments, reviewer feedback)
