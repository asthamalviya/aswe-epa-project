# S20: Technical Problem Solving

## What This KSB Is About
The skill to diagnose complex technical problems, identify root causes, and implement effective solutions. Includes troubleshooting methodology, evidence gathering, hypothesis testing, and solution validation.

## Why It Matters
Anyone can apply a quick fix. S20 is about systematically finding the real problem, not just treating symptoms. The difference between "restart the service" and "database connection pool exhausted—here's the permanent fix."

## What Examiners Want to See
- Structured troubleshooting approach (symptom → logs → hypothesis → test → fix)
- Root cause analysis (not band-aid solutions)
- Evidence of investigating multiple theories before committing to one
- Solution validation and monitoring
- Documentation of what was learned

## Grade Feedback from Examiner
**Your Grade:** A
**Feedback:** "Good problem-solving approach. Root cause identified correctly."
**To Improve:** Show more detailed troubleshooting process. Include logs, monitoring data, and how you ruled out alternative causes.
