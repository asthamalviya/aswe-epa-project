## 📝 File Types in Each KSB Folder

Every KSB folder contains (or should contain):

1. **details.md** - What the KSB is about
   - Simple 1-page explanation
   - Why it matters
   - What examiners want to see

2. **evidence-submitted.md** - What you showed examiners
   - Summary of your original submission
   - Examiner's feedback
   - What you did well
   - What held you back (the gap)

3. **evidence-new.md** - NEW evidence to improve your grade
   - Addresses the gap from evidence-submitted.md
   - Detailed examples and explanations
   - Tables, comparisons, calculations
   - Real business scenarios
   - Simple summary for examiner

4. **[Screenshots]** - Visual evidence from your PDF
   - Name clearly: `governance-framework.png`
   - Store in the KSB folder
   - Reference in evidence-new.md

## ❓ FAQs

**Q: Do I need to fill all modules?**
A: If you've submitted all 7 modules + capstone + portfolio, yes. If fewer, just do the ones you submitted.

**Q: Can I use Module 1 as template for Module 5?**
A: Yes! Same 3-file structure works for all KSBs. Adjust content for your specific KSB.

**Q: Should I add ALL screenshots or just key ones?**
A: Add 1-3 key screenshots per KSB showing your most important evidence.

**Q: How do I know what to customize?**
A: Read the `evidence-submitted.md` file - it lists what examiners wanted. Customize to address those gaps.

**Q: What if my numbers are different from examples?**
A: Replace every example number with YOUR actual data. That's the whole point - make it specific to your project.
