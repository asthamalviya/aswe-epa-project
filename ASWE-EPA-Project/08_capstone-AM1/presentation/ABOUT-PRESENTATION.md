# Capstone Presentation (AM1, part 2)

**What it is:** the second part of the capstone assessment. It happens **after** you submit the report, so the assessor has already read it.
**Format:** 30-minute presentation, then 30 minutes of questions, with up to 10% buffer.
**Assessed against:** the 25 AM1 KSBs only. The AM2 portfolio discussion is separate (`../../09_portfolio-AM2/`).
**What the brief requires it to cover:** project overview; scope including KPIs; summary of actions; outcomes and how they were achieved; strategic recommendations.

## How it relates to the report
- Same project, same figures. Every number on a slide must match the report exactly.
- The slides show judgement: why you chose each option, what you compared it with, what you would change.
- Write the final slides after the report is final.
