# About the Capstone (AM1)

## This is NOT tied to any specific module

The Capstone Project is Assessment Method 1 (AM1) — a completely standalone assessment.

It is a **~8,000 word written report** about a real work project you have undertaken as part
of your apprenticeship job role. You choose the project. It does not have to relate to
Module 7 or any other specific module.

## What it covers

The report must demonstrate your ability to:
- Identify a real business problem and propose a solution
- Plan and manage a technical project
- Apply software engineering skills to build/improve something real
- Analyse outcomes and reflect on your learning

## How it relates to modules

Your modules give you the **knowledge and skills** to draw upon in the capstone — but the
capstone project itself comes from your **actual job**, not from module assignments.

You might naturally reference concepts from any module (e.g. architecture from Module 3,
testing from Module 7, DevOps from Module 6) but the project stands independently.
