# ASWE EPA Project Context

This workspace belongs to an Advanced Software Engineering (ASWE) apprentice preparing for their End Point Assessment (EPA).

## About the User

- Studying the ASWE apprenticeship standard with Multiverse
- Preparing for EPA which consists of:
  - **AM1**: Capstone Project report (~8,000 words)
  - **AM2**: Portfolio of evidence mapped to KSBs
  - **Presentation/Interview**: Synoptic discussion with an examiner

## Key Files to Know

- `ASWE-EPA-Project/README.md` — full project overview
- `ASWE-EPA-Project/00_overview/` — EPA guidance and capstone brief PDFs
- `ASWE-EPA-Project/01_capstone-AM1/` — Capstone project templates and sections
- `ASWE-EPA-Project/02_portfolio-AM2/` — Module-specific KSB readiness pages
- `ASWE-EPA-Project/03_ksb-reference/` — Knowledge, Skills, Behaviours reference
- `ASWE-EPA-Project/06_evidence/` — User's own evidence files
- `ASWE-EPA-Project/07_presentation/` — Presentation prep materials

## KSB Framework

The user must demonstrate these KSBs:

**Knowledge**: K6, K7, K8, K9, K10, K11, K12, K14, K16, K19, K20, K21, K22, K23, K24, K28
**Skills**: S4, S7, S8, S9, S10, S11, S12, S15, S20, S21, S23
**Behaviours**: B1, B2, B4, B6, B7, B8

## How to Help

- When the user asks about KSBs, refer to the relevant readiness pages in `03_ksb-reference/`
- When helping with writing, aim for Distinction-level language (evaluate, justify, reflect)
- When reviewing evidence, check it against the grading descriptors
- Always suggest saving new work to appropriate folders in `ASWE-EPA-Project/`
- Remind the user to map all work back to specific KSBs

## Grading Target

Always help the user aim for **Distinction**. Even when they ask for Pass-level help, suggest improvements that would push them higher.
